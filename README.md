# ai-trading-agent

First test of using AI agents to trade the New York and Asia sessions with a breakout strategy.

The tool will use Python, C++, and Rust. It observes market conditions in the first 5-15 minutes of open to decide whether to take a trade.

See [trading-rules.md](trading-rules.md) for the rules the AI agents must follow.
